# منظومة متجر ونظام المأمون الإلكتروني الحديث (Al-Mamon Enterprise Storefront & Cloud ERP)

## نظرة عامة
تم بناء وترحيل منظومة **متجر المأمون الإلكتروني الحديث (المأمون ستور)** بالكامل لتعمل على البنية السحابية المستقلة الخاصة بالمتجر (**Supabase PostgreSQL + Cloudflare Edge + GitHub**) مع تطابق 100% في كافة الأدوات والتصميم والبيانات مع النسخة التجريبية (`Almamon.exe` للويندوز و `app.yrbso.net/almamon` للويب) وإضافة ميزات احترافية متقدمة.

### البيانات المرحّلة فعلياً في قاعدة البيانات السحابية الجديدة (`nlxiixqzgkvjfntggekt`):
- **1,937 صنفاً حقيقياً** بكامل صورها وأسعارها (المفرد والجملة والتكلفة) وأرقامها والباركود والمواصفات.
- **13 مجموعة رئيسية** و **122 تصنيفاً فرعياً** مرتبطة بشجرة المتجر والمخازن.
- **8 طرق دفع إلكترونية وبنكية** (الدفع عند الاستلام، من رصيدي، حاسب الكريمي، محفظة كاش، جوالي، بيس بنك الأمل، سبأ كاش، جيب) باسم: **مأمون علي حمود العمري (731002020 / 781002020)**.
- **4 عملات متزامنة** (`YER ريال يمني`, `SAR ريال سعودي`, `YRS يمني جديد`, `USD دولار أمريكي`).
- **شجرة الحسابات (15 حساباً رئيسياً وفرعياً)**، ميزان المراجعة بالمجاميع والأرصدة، السندات المالية، الفواتير، وطلبات المتجر.
